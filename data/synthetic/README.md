# Synthetic Chapter 1 fixtures

All records are fictional. `claim-0001.json` exercises a valid application request. `claim-cross-tenant.json` exercises rejection before model invocation. These files do not represent real policyholders or real policies. The offline client returns a constant labeled fixture; it does not assess the description, coverage, loss or payment.

The claim schema is deliberately minimal in Chapter 1. Later chapters add provenance, dates, extraction and policy evidence without silently changing version 1's field contract.
